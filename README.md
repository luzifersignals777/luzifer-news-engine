# Luzifer 5.8 — Live News Engine

This package keeps the Luzifer 5.7 signal engine intact and adds a real external news bridge.

## What it does

- BUY/SELL are still generated by Luzifer.
- The external engine reads the live economic calendar.
- It evaluates USD-related events for GOLD/XAUUSD.
- It uses importance, event time, actual, forecast and previous.
- It calculates a news confirmation score.
- News never creates or blocks a BUY/SELL.

## Important technical point

Pine Script cannot make arbitrary HTTP requests to an external REST/WebSocket API. TradingView webhooks are outbound HTTP POST requests to an external server. Therefore the live news connection lives in `news-engine/`, while Pine sends the existing signal to that engine.

Trading Economics documents both calendar snapshots with Actual/Forecast/Importance fields and live calendar streaming. The REST calendar is used here for upcoming events and releases. A paid/authorized API key is required for the external provider.

## 1. News engine

In `news-engine`:

```bash
npm install
copy .env.example .env
```

Set:

- `WEBHOOK_TOKEN`
- `TRADING_ECONOMICS_API_KEY`

Then:

```bash
npm start
```

The public endpoint must be HTTPS on port 443 (or standard HTTPS port) for TradingView webhooks.

Webhook endpoint:

`POST /webhook/tradingview`

Health:

`GET /health`

Status:

`GET /api/status`

## 2. Pine

Open `pine/Luzifer_5_8.pine` in TradingView.

Set the same token in the `07 - LIVE NEWS BRIDGE` input.

Create a TradingView alert using:

- Condition: `Luzifer 5.8...`
- Trigger: `alert() function calls` / the alert option that listens to `alert()` calls.
- Webhook URL: `https://YOUR-DOMAIN/webhook/tradingview`

Do NOT put API keys in the Pine code or webhook body.

## 3. What you will receive

For an existing BUY/SELL the engine returns:

- CONFIRMED
- NEUTRAL
- CONTRARY
- upcoming high-impact event
- recent high-impact event
- actual / forecast / previous
- news score

The chart signal itself is not blocked or replaced.

## 4. Final deployment requirement

The package is complete, but I cannot honestly claim it is already live until a real external HTTPS server is deployed and a valid Trading Economics API credential is supplied. TradingView requires a reachable webhook endpoint; localhost is not enough.
